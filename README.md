# лабка 13 веб-программирование 
# Аутентификация жүйесі — тіркелу, кіру, шығу функциялары. Class-based view емес, жеке функциялық view-лар арқылы (register_view, login_view, logout_view). Django-ның authenticate(), login(), logout() функциялары тікелей қолданылды.
# Note моделі — пайдаланушыға байланған жазба моделі. Әр жазбада тақырып, мазмұн, автор (ForeignKey → User), жасалған/өзгертілген уақыт бар.
# CRUD операциялары — жазба қосу, өзгерту, жою. Тек меншік иесі өзінің жазбасын өзгерте алады (get_object_or_404(Note, pk=pk, author=request.user)).
# Қорғалған беттер — @login_required декораторы dashboard, қосу, өзгерту, жою беттерін жабады. Кірмеген пайдаланушы автоматты login бетіне бағытталады.
# Динамикалық UI — шаблондарда {% if user.is_authenticated %} арқылы интерфейс өзгереді: кірген адам атын, «Шығу» батырмасын, өзінің жазбаларын басқару батырмаларын көреді; анонимді пайдаланушы тек оқи алады.
